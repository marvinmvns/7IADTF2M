🧬 Genetic Algorithm VRP API

Vehicle Routing Problem Optimization with Genetic Algorithms

API RESTful para otimização de rotas de entrega de medicamentos e suprimentos para hospitais usando Algoritmos Genéticos. Baseado em dados reais de hospitais do estado de São Paulo.

Características Principais

  • 24 Operadores Genéticos: 8 métodos de seleção, 8 de crossover, 8 de mutação
  • Multi-objetivo: Otimização simultânea de distância, prioridades, capacidade e autonomia
  • Dados Reais: Coordenadas geográficas de hospitais de São Paulo
  • Execução Assíncrona: Processamento em background com consulta de status
  • Persistência Completa: Histórico de experimentos em SQLite
